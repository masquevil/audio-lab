# 人声基础模拟实施记录

原始需求：[人声基础模拟](../pools/2026-10-30%20人声基础模拟.md)

## 范围与方案

当前确认范围：使用 KlattSyn 开源 DSP 引擎配合 Web Audio，支持六元音 × 四声、男女声合成预设。最初“不引入依赖、纯原生节点合成”的约束已由后续技术路线确认替代；不调用系统朗读、神经模型或外部语音服务。此次验证声学参数可控性，不承诺自然中文 TTS 可行。

- 新增 `/voice` 页面、首页与导航入口。
- 当前链路：Klatt 自然声门激励与六共振峰串联声道生成 PCM，项目代码整音调幅与包络，再由 Web Audio 缓冲区播放。此前参考 [ds_sound.html](../pools/ds_sound.html) 的锯齿源/并联滤波方案已替换，历史返修记录保留在下文。
- 单音试听、四声连续对比、停止、音量与时长调节、基频轮廓及共振峰展示。
- 暂不做辅音、组合音、任意文字、年龄和磁性滑块；三声为完整降升，不做语流变调。
- 每次试听独占音频上下文；重播、停止、卸载取消旧请求并释放节点和上下文。

## 验收标准

1. 六元音与四声可选择试听，男女预设可切换；参数在下次播放生效。
2. 连续四声按一至四声播放，有间隔；可停止、重播，离开页面不残留。
3. 初始不发声；不支持或启动失败有提示；移动布局不横向溢出。
4. 页面明确展示合成范围与限制，人工试听元音辨识度、音色差异及声调效果。

## 技术路线补充评审与确认

此前调研与小样确认没有充分说明第三方库接管核心波形计算，也未完整比较使用库与自研的区别；整套替换先于充分技术评审，不能由事后代码自审或构建检查替代。研发已向 PM 说明，PM 在理解以下职责及取舍后明确同意继续使用此库；这是补充确认，不追溯宣称此前流程已完整执行。

- **决策**：保留 klatt-syn 1.0.9，定位为基于开源参数合成引擎的人声实验，而非自主实现底层人声算法。
- **职责**：库依据 F0、声门开放比例、气息、频谱倾斜、共振峰频率/带宽等参数计算 PCM；项目负责元音配置、声调参数帧、男女预设、整音调幅/包络及 Web Audio 播放、音量、排程和清理。当前部分声源参数沿用库演示默认值，不是经真人拟合的音色模型。
- **备选比较**：原生节点自研可减少依赖，但此前实现听感不合格；完整自研 DSP 可控制算法细节，但需承担声门、谐振器、数值稳定性和维护验证成本。使用库复用成熟算法，PM 已认可小样明显更好；仍不等于自然中文 TTS 或整套听感已通过验收。
- **运行边界**：浏览器主线程先生成完整短音，再将 Float64 PCM 调幅为 Float32 写入 AudioBuffer 播放，无 WAV/MP3 编解码。设置作用于下次生成，不实时改变已生成音频。
- **已知风险**：长文本/移动设备的主线程性能尚未验证；中文音素、过渡、变调及韵律仍需另外实现；库有发布接口适配问题（const enum 无运行时导出）；新增长期维护依赖 klatt-syn 与 dsp-collection。
- **未完成检查**：完整依赖安全/维护状况审查仍未完成，不以安装和构建成功宣称通过。
- **当前状态**：技术路线已获明确确认，代码本轮不变；保留整套听感待验收状态，不据此扩展辅音、文本朗读或大型语料下载。
