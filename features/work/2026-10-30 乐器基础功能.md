## 技术重构（PM 已确认）

保持功能、界面和音色参数不变，按职责划分页面私有模块：

| 模块 | 职责 |
| --- | --- |
| instruments.ts | 音色配置及推导的 TimbreId、八度类型、音符与按键映射 |
| InstrumentKeyboard.vue | 键盘展示与样式、输入来源跟踪、按下/释放事件及输入监听清理 |
| instrumentVoice.ts | 单音波形、包络、释放、幂等节点清理，不依赖 Vue |
| useInstrument.ts | 音频会话、请求取消、复音与生命周期；只读状态及 setTimbre/setVolume 操作 |
| InstrumentsView.vue | 页面组合和控制栏，不直接修改 hook 状态 |

同音输入按来源持有，最后一个来源释放时才释放音符。请求令牌区分异步启动与实际声音，resume 完成并成功创建声音后才标记演奏。清理声音统一使用 dispose，音色切换由 hook 内部处理；重复选择当前音色不重置。合并 view 重复样式声明，琴键样式移入键盘组件。未新增依赖或共享基础设施。
