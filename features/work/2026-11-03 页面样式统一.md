# 页面样式统一实施记录

需求来源：PM 会话反馈（2026-11-03），未单独建立 pools 文件。

## 目标与范围

统一首页与三个内页的页头、操作按钮和页面留白，去掉各页面重复且已经漂移的样式；首页保留更大的顶部留白和大标题。

- 新增共享 `PageHeader`：eyebrow、标题、强调片段、简介；内页标题 28px，首页 32px（≤700px 回到 28px）。
- 新增共享 `LabButton`：`type` 区分主次（primary/secondary），`size` 区分密度（default/compact）；声部开关用"播放/停止"两个按钮表达动作，`LabButton` 不承担选中状态。替换人声、环境音、参考试听的操作按钮。
- 新增共享 `LabNotes`：承载“实现说明”折叠区，替换人声和环境音各自的标题与段落样式。
- 新增共享 `LabPageBody`：统一页面最大宽度、水平留白与上下留白；首页用 `size="large"` 保留更大顶部留白。
- `main.scss` 增加页面布局变量：`--page-max-width: 1080px`、`--page-gutter-horizontal`（水平留白，桌面 32px、≤700px 16px）、`--page-padding-top`、`--page-padding-bottom`；导航与 `LabPageBody` 共用。
- 折叠区文案按 PM 要求精简：人声页删去“男声/女声仅为两组声学预设”“自然中文还需要音素过渡、韵律与文本处理”两句，环境音页删去“每次节奏不同”；只保留结论性限制，不属于样式改动。
- `main.scss` 增加排版、间距、动效与圆角 token：12/14/16/18/24/28/32/40 字号阶、1.25/1.4/1.6 行高、4px 间距栅格、0.15s 过渡、4/8/12 圆角。
- 间距只使用 4px 档位：撤销 6/10/14px 例外，11 处历史值按最近档位统一（14→12、10→12、6→8，窄屏 padding 10→12）。
- 间距档位由 10 档缩到 7 档：保留 4/8/12/16/24/32/40，去掉 20/28/36；导航与控制行 20→24，首页网格 28→32。
- 尺寸与间距分开：声部图标盒改用组件内 `--layer-icon-size`；首页描述区最小高度按两行正文 `calc()` 计算，并新增 `--line-height-body` token。
- 颜色 token 按角色分类：页面/表面/控件背景、主/次文本、强调与弱强调、危险色；移除页面局部 `--color-alert`。
- 全项目字号改用 token，12px 为下限；控件字号由 reset 继承页面字号，按钮内边距统一为 8×12px，紧凑按钮为 4×12px。
- 移除 `<small>` 等用标签改变字号的写法，改用 `<span>` + class；与字号同批清理字重 650→600、离格间距和圆角。
- 新增 `docs/design-system/`，按 foundations、tokens、components、contributing 拆分，记录抽象规范、命名、组件边界与变更流程。

## 不做

- 不统一各页内容网格的断点和信息密度（环境音 960/560、乐器 600、人声 700、首页 900/600 保留）。
- 音色 tab、琴键、LabRadio 不改为 LabButton：它们分别是 tab、乐器键盘和单选项，不是操作按钮的变体。
- 不改音频、录音、路由与交互逻辑。

## 验收标准

- 1280 / 900 / 768 / 700 / 600 / 375 下，三个内页页头顶部与高度一致，导航与页面内容左边缘对齐。
- 首页页头允许更高：顶部 32px、桌面标题 32px，≤700px 标题 28px。
- 按钮主次、禁用、悬停与选中状态正常；录音、试听、环境音声部开关行为不变。
- `pnpm check` 通过。

## 设计规范依据

- [Tailwind CSS](https://tailwindcss.com/docs/font-size)：字号阶 12/14/16/18/20/24/30，12px 为最小档。
- [IBM Carbon](https://carbondesignsystem.com/elements/typography/overview/)：12px 起步，14/16px 为正文基数，字号保持偶数阶。
- [GitHub Primer](https://primer.style/foundations/primitives/typography)：caption 12、body 14、标题 20/32/40，行高 1.25–1.75。
- [Ant Design](https://ant.design/docs/spec/font)：正文 14/22，建议控制字号数量，字重以 400/500/600 为主。
- 本项目采用 12px 下限和偶数阶：12 / 14 / 16 / 18 / 24 / 28 / 32 / 40；标题行高 1.25，面板/卡片标题 1.4，正文 1.6。个别移动系统存在 11px 辅助标签，本项目按 Web 可读性不采用。

| 700 / 600 | 16 | 72 | 89.4 | 80 | 62.2 | 28 |

- 内页标题 28/35，首页标题 32/40；≤700px 首页标题 28/35。
- 导航在 1280 / 700 / 375 / 360 / 320 下均为 48px 单行；导航链接左边缘与 eyebrow 一致（132 / 16）；四页在 1280 与 375 均无横向溢出。
- 1280 / 375 全页面元素扫描：计算字号最小为 12px，不再出现 8/10/11/13/15/17/22/23/26 等值。
- 375px 下黑键宽 20.66px、标签单行宽 20.5–22.6px，横向溢出不超过 2px 且不换行；保留 12px 下限并加 `white-space: nowrap` 固定单行。
- 指针与悬停：`LabButton`、`LabRadio`、琴键、音色 tab、说明折叠区的计算 `cursor` 均为 `pointer`，禁用按钮为 `not-allowed`，原生滑块与 `select` 保持浏览器默认；默认按钮悬停底色 `rgb(12,16,22)` → `rgb(26,36,48)`，主按钮与选中项保持强调底色并提亮 1.12。
- 间距与尺寸：脚本扫描 `gap/padding/margin` 不再出现 6/10/14px；首页描述区最小高度计算为 38.4px（2 × 12px × 1.6），声部图标盒 32px 由组件本地变量提供。
- 间距缩表：全项目只引用 1/2/3/4/6/8/10 档，无 20/28/36 残留；导航与乐器控制行 gap 为 24px，首页网格 margin 为 32px。
- 导航：1280 / 700 / 375 / 360 / 320 下高度 48px、单行；导航与页面容器的水平内边距一致（32 / 16），链接用 `padding-inline` 提供间距（≥360 为 12px、文字间隔 24px；≤359 收为 4px），最后一项文字右边缘与页面内容右边界对齐；品牌文字左边缘 132（窄屏 16）与 eyebrow 对齐；链接悬停时文字由次色变为主色。
- 交互回归：环境音声部开关（播放→停止→播放，按钮与卡片状态同步）、人声试听（进入播放态并在 0.4s 后自动结束）、参考试听与停止、录音开始/停止与结果生成均正常；页面加载无应用错误或 Vue 警告。
- `pnpm check` 通过：ESLint、Prettier、vue-tsc、生产构建。

## 技术审查与修复

同一 AI 自审，不是独立 review：

- 水平/垂直变量分开命名：`--page-gutter-horizontal` 与 `--page-padding-top/bottom`。
- 字号：8/10/11/13/15/17/22/23/26 等非规范值统一映射到 12/14/16/18/24；键盘标签 8/10 也提升到 12。
- 移除 `<small>` 标签，改用 `<span>` + class；字号由 token 控制，不再依赖标签的默认缩小样式。
- 新增“标签与组件边界”规范：原生元素承担行为，样式与复用由组件封装；展示容器使用 `div`/`section`，不为卡片使用 `article`；项目不做读屏/ARIA 专项。`details`/`summary` 在需要自定义样式、动画或受控状态时封装为组件。
- 颜色按角色命名：`--color-bg-page/surface/control`、`--color-text-primary/secondary`、`--color-accent-subtle`、`--color-danger`；原始色值只保留在 token 定义。
- 字重 650→600；标题行高 1.25，面板/卡片标题 1.4；正文沿用 1.6。
- 间距 token `--space-1..10` 与动效/状态 token 落地到共享组件和页面布局；圆角统一为 4/8/12。
- 删除页头未使用的 `heading-main` class；700px 断点同时控制页面留白和页头堆叠，已在两处注释说明耦合关系。
- 未给 Vue props 追加 `readonly`：props 本身已是只读，数组内容只在组件内消费。
- 完整约定写入 `docs/design-system/`；文档只保留 token、颜色、排版、间距、组件边界等抽象规范，不列项目组件清单或取舍历史。
- 声部开关改为"播放/停止"两个按钮：按钮只表达动作层级，播放状态由卡片边框与按钮文案体现，不再把播放状态建模成按钮选中态。
- `LabRadio`/`LabRadioGroup` 尺寸档 `medium` 统一为 `default`，与 `LabButton` 一致。
- 首页网格间距改用 token，去掉 28px 原始值。
- 撤销“密集控件允许 6/10/14”的例外，文档只承认比例尺档位；历史值按最近档收进 token（声部卡片、音色 tab、大字符说明的 14→12，标题与状态间距 10→12，强度区 6→8，窄屏 tab padding 10→12）。
- `--space-*` 只用于间距；图标盒尺寸由组件本地变量维护，文本区最小高度由 `calc(2 × 正文字号 × 行高)` 推导。
- 间距缩表：档位从 10 档减到 7 档（4/8/12/16/24/32/40），档号继续表示 4px 倍数；移除 20/28/36，清单外档位不再提供。（本轮曾临时补齐 28/36 档，随后缩表撤销。）
- `reset.scss` 保持纯净：移除 `accent-color` 的变量消费，滑块强调色移入 `main.scss`；控件恢复 `font-family: inherit`，不重复字体栈。
- 删除 4 个页面重复的容器声明，改由共享 `LabPageBody` 承担。
- CONTRIBUTING 样式条目与设计系统去重，颜色角色、比例尺档位和断点规则只在设计系统维护。
- 悬停可感知度：新增 `--color-bg-control-hover`（控件悬停表面），默认按钮与未选中选项悬停换底色；主按钮与选中项保持强调填充并提亮 1.12。
- 导航固定 48px：高度用组件内 `--navigation-height`；导航水平内边距与 `LabPageBody` 一样使用 `--page-gutter-horizontal`，链接间距由 `padding-inline` 提供，品牌与链接组用同值负 margin 把文字对齐到页面栅格；窄屏隐藏品牌副标题，≤359px 收一档内边距。
- 复跑 `pnpm check`，1280/700/375 复测页头高度、导航对齐、字号下限、按钮状态和横向溢出。
- 本轮复审：移除 `AmbienceCard` 的 `article` 容器，卡片改用 `div`；项目明确不做读屏/ARIA/无障碍专项。
- `CONTRIBUTING` 样式示例改用 `--color-text-primary` 与 `--font-size-title`，与当前 token 一致。
- 设计系统补 `LabButton`、`LabPageBody`、`PageHeader`、`LabNotes`、`LabRouteView` 文档与索引；token 维护改为代码与文档各一份、不在多处重复。
- 乐器页文案（含删除“非真实乐器采样”）由作者本人决定，不作为评审或验收问题。
