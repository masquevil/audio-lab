## 最终方案与决策

- 经 PM 确认恢复 Vue Router 自动路由：pages 仅路由入口，views 承载实际页面；App 渲染 RouterView，首页入口引用 HomeView。删除 useTone，共享 hooks 不放页面私有音频参数和文案；目录职责与放置规则集中补充到 CONTRIBUTING，skills 引用检查。
- 沿用 VITE_TARGET_ENV=pages/hash 时 hash、其他情况 history 的环境策略，CI 设置 pages，并接入自动路由 HMR。不复制参考项目业务守卫。资源 base 恢复初始读取到的 getBase()：pages/默认均为 `/`，撤销自行增加的基路径环境变量及 CI 配置。
- 路由类型生成在 src/router/typed-router.d.ts，作为类型源保留，不手工编辑或格式化；已恢复路由依赖并同步锁文件，未引入其他页面功能。

- 样式统一 SCSS，内部优先原生 CSS；颜色采用语义化 CSS 变量，页面样式 scoped，专用 class 使用多词 kebab-case。参考 trpg-saikou 的变量组织原则，不复制多主题架构。
- Vue/TypeScript 基于官方生态规范；ESLint 检查 SFC 块间及 import 后空行，语义 import 分组等由最终 review 检查。
- 表格使用 Prettier 原生 Markdown override：printWidth=1、proseWrap=never、embeddedLanguageFormatting=off，避免视觉对齐及代码块被极小行宽拆散；代码文件行宽仍为 100，表格分隔线沿用默认输出。
- 曾调研自定义/第三方格式插件，最终不采用，已删除本地实现及临时调研包，无新增插件依赖。按 PM 要求删除格式配置专项测试及脚本引用，升级 Prettier 时人工检查间接配置行为。
- 部署移除强推并检查工作区，CI 执行质量门禁。未执行远程推送或部署。
