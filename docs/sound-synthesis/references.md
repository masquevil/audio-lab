# 参考素材来源

本项目所有声音都在运行时由 Web Audio 合成，**产品不包含任何音频采样**。下面是开发期用于学习结构与听感的参考录音，仅存在于本地忽略目录，不进入仓库或构建产物。

## 环境声（按类别）

| 来源 | 许可 | 用法 |
| --- | --- | --- |
| [Moodist](https://github.com/remvze/moodist) | MIT | 雨声分类（Light / Heavy / Window / Car Roof）、雷声事件、篝火、风声的**结构测量**：逐频段能量、事件包络、调制谱 |
| [Ambiently](https://github.com/abhinandansharma/ambiently/tree/main/demo/public/sounds) | CC0 | 雨声、雷声、风声、篝火的整体听感对照 |
| Mixkit（本地片段） | 仅本地分析 | 多段同类样本，用于确认参考分布的跨度，避免只对一个样本调参 |

## 具体学习了什么

- **雷声**：从中提取 24 个 1/3 倍频程 × 20ms 的**能量包络**，量化后作为模板驱动运行时合成（见 [measurements](measurements.md)）；A/B 结构、起音时间、衰减率、调制谱均来自这批参考的中位数。
- **雨声**：轻雨取自 Moodist Light Rain 的 27 段 1/3 倍频程 × 20ms 能量包络（含 8k/10k/12.5k 三个高频段），运行时用分块 STFT 重建并混入共同成分以贴近参考的左右相关度；暴雨仍是程序化雨幕。两者的“命中/秒、电平分位、频段占比、空气感”对照见 [measurements](measurements.md)。
- **篝火**：参考 Moodist Campfire 的瞬态结构——能量几乎全在 2–10kHz 的爆裂事件上，低频占比只有 -11dB。产品因此用“密集微爆裂”做底纹，而不是噪声层。
- **风声**：只用参考校正事件密度、频段配比与呼啸时长，实现完全由代码生成。

## 边界

- 不复制、不转码、不打包任何第三方音频；仓库里只有数值参数（频段电平、包络点）与生成代码。
- 参考录音的许可以上表为准；若未来更换参考，需要同样确认许可，并在此文件登记。
