# 实测基准

本文件记录参考集的实测数值，作为验收时的对照。所有数字由 `tools/sound/` 下的脚本产生，可用同样的参考集复现。

## 指标定义

| 指标 | 计算方式 | 用途 |
| --- | --- | --- |
| 频段占比 | 4096 点 Hann 窗逐帧 FFT，按频段求和后取相对总能量的 dB | 判断音色倾斜 |
| 包络 CV | 100ms 帧 RMS 的变异系数 | 起伏强弱 |
| 慢调制占比 | 10ms 电平的对数谱中 0.15–3Hz 的能量占比 | 是否有慢速涨落 |
| 调制谱分布 | 同上，按 0.1–51.2Hz 分段 | 起伏落在哪个尺度 |
| tonality | 80–600Hz 带通后 200ms 帧的自相关峰值（中位、>0.5 的帧占比） | 是否被听成音高 |
| P(Thunder) | AudioSet AST 对 10s 窗取 sigmoid 概率平均 | 人会把这段叫什么 |

tonality 需要标定（本项目实测）：宽带噪声 80–600Hz = **0.16**（>0.5 的帧 0%）；窄带噪声 100–200Hz = **0.45**（27.9%）；57Hz 周期脉冲串 = **0.91**（100%）。

## 参考集（10 段真实雷声）

- P(Thunder)：**0.001–0.895**，中位 0.373。其中两段（1279/1280，极低频闷雷）只有 0.001/0.014 —— 分类器对这类声音不敏感，不能据此判定"不是雷"。
- A 段（起爆）：起音中位 **500ms**（40–2910ms），持续中位 **0.61s**（0.10–2.96s）。
- A 段频谱：100–200Hz **-5.8dB**、200–400Hz **-5.6dB**、3.2–8kHz **-36.4dB**（相对总能量）。
- B 段频谱与 A 段几乎相同（100–200Hz -4.6dB、200–400Hz -5.4dB）：**A/B 不是两种音色，差别在包络**。
- B 段起伏间隔中位 **45ms**（40–80ms，约 22 次/秒），整体衰减 **-1 ~ -4 dB/s**，B 段峰值仍达全局的 **0.85**。
- 频段与总包络的相关：**0.59–0.93**（中位 0.92），不是 1.0。
- 高频衰减快于低频：2.8kHz 段 **-5.5 dB/s**，低频 **-3.2 dB/s**。
- 调制谱：**24.6%** 在 0.1–0.2Hz，约 **26%** 在 12.8–51.2Hz。

## 声部响度（端到端实测）

测法：`createAmbienceSession()` 只开一个声部、默认强度，录 `MediaRecorder` 输出，解码后算整段 RMS（含压限器）。数字为浏览器实测；篝火增益在测量后调整过（现为 2.2 / 0.6），该行 RMS 待复测。

| 声部 | 纹理基准 | `maxGain` / `gainCurve` | 实测 RMS |
| --- | --- | --- | --- |
| 风（0.4） | 运行时合成 | 0.75 / 0.7 | -29.4 dB |
| 轻雨（0.35，阈值以下只有轻雨） | -23 dB | 0.78 / 0.8 | -31.6 dB |
| 暴雨（1.0） | -20 dB | 0.78 / 0.8 | -22.3 dB |
| 篝火（0.4） | -30 dB（底纹） | 2.2 / 0.6 | 待复测（旧值 -31 ~ -34 dB） |
| 雷（0.3，含静默间隔） | -21.5 dB（限峰后） | 1.05 / 0.45 | -26 ~ -30 dB |

- 轻雨比暴雨低 3dB 是刻意的：它几乎全是高频，等 RMS 时听感更响。
- 篝火底纹只提供“一直在烧”的连续感（中频连续层 + 每秒约 30 次微爆），比响爆低约 16dB；稀疏的噼/啪/噗由运行时随机排程叠加，强度主要改变密度。底纹增益随强度 0.06→0.08。
- 雷是间歇事件，RMS 随窗口内落雷次数变化，峰值帧约 -14dB。

## 小雨的“清透感”：实测差在哪

同一套指标（立体声相关、频段能量占比、2.5–12kHz 包络的 p99−p50）对比：

| 指标 | Moodist Light Rain | 之前的模板重建 | 当前 |
| --- | --- | --- | --- |
| 左右声道相关 | 0.49 | **0.00** | 0.45 |
| side / mid | -4.6 dB | **0.0 dB** | -4.2 dB |
| 200–800Hz 浑浊占比 | -16.4 dB | -18.2 dB | -19.6 dB |
| 2.5–12kHz 占比 | -1.4 dB | -1.3 dB | -1.3 dB |
| **8kHz 以上“空气感”** | **-6.9 dB** | **-32.0 dB** | **-5.5 dB** |
| 2.5–12kHz 包络 p99−p50 | 5.6 dB | 3.7 dB | 3.4 dB |

两处根因：

1. **模板最高只到 6.3kHz**（24 个 1/3 倍频程），重建后 8kHz 以上基本是空的（-32dB vs -6.9dB）——这正是“清透感”的主要来源。现在模板扩到 27 段（补 8k / 10k / 12.5k），文件 33→41KB。
2. **两声道完全去相关**：`renderEnvelopeTexture` 对左右声道各生成一次随机相位，相关度是 0，听感“空、散”。按参考的相关度 0.49，混入 0.5 倍的共同成分（`L' = 0.8L + 0.5·mid`），实测回到 0.45。

剩余差距是撞击锐度（3.4 vs 5.6dB），受 20ms 包络帧限制；要再提升需要把模板分辨率降到 5ms（数据约 4 倍、chunk +80KB），本轮未做。

## 篝火底纹：Moodist Campfire 的实际结构

把参考录音按 1ms 帧的 2–12kHz 包络拆成“底纹帧”（<中位+3dB）与“响爆帧”（>中位+10dB）：

| 指标 | Moodist Campfire |
| --- | --- |
| 底纹 / 响爆帧占比 | 75% / 7.3% |
| 底纹电平 / 响爆电平 | -32.7dB / -17.4dB（**响爆高出 15.3dB**） |
| 底纹包络 p20 / p50 / p90 | -34.0 / -31.8 / -23.8（**p20 只比中位低 2.2dB → 底纹是连续的**） |
| 底纹自身微峰密度 | **81.5 次/秒** |
| 底纹慢调制占比 | 0.40（底纹本身有明显起伏） |

结论：参考的“底纹”是**连续的高频嘶 + 每秒约 80 次、约 2ms 的微爆**，整体比响爆低 15dB；它既不是纯噪声（会听出“呼呼”），也不是纯点击数（会听出“沙沙的响指”）。

产品实现（`createEmberBedTexture`，20 秒循环，渲染 32ms）：低中频连续层（pink 1.2k/250、2.5k/600，少量 3.8k/1.2k）\+ 每秒 30 次微爆（1.5–4ms、0.5–6kHz）+ 每秒 6 次中频碎裂。 **第一版做成了每秒 80 次高频微爆，PM 反馈“像浑身是毛的毛毛虫”**——颗粒太密太碎会听成绒毛感，因此把颗粒降到 30 次/秒、时长拉长、频段压到中频，重心交给连续层。实测底纹包络 p20/p50/p90 = −20.0/−18.7/−10.6（Δ1.3 / Δ8.1 dB，参考 Δ2.2 / Δ8.0）。混音电平 `bedGain = 0.06→0.08`：底纹约 −46dB、响爆 −30dB，**相差约 16dB（PM 要求“几乎听不到”）**。

关键结论：**呼啸不是独立事件，而是阵风的伴生现象**——参考里呼啸出现时整体风量同时高约 8dB，所以实现上用同一条包络同时驱动整层风量（`gustGain`）与啸叫门（`howlGate`），形状为“轻微呼啸 → 风量激增 → 快速回落 → 消失”，约 1/3 的事件有第二次起伏。

| --- | --- | --- | --- | --- | --- |
| Moodist Campfire | 56.4 | 2 ms | 24.4% | 5.0 / 14.5 / 31.2 dB | -28.6/-28.1/-20.0/-18.1/-19.3/-14.5/-14.2/-13.6 |

关键差别是**事件电平**：参考的爆裂只比底纹中位高 5dB，说明底纹本身就是有声的连续柴火；“静音+点击”做出的是 21dB，听起来像零星响指而不是燃烧。

运行时响爆补齐参考里那些 +30dB 的孤立大响。

> 当前状态：底纹经过三轮才定稿——第一版（brown/pink 噪声）和“静音+点击”都被否决，第三版按上面的实测重做为“中频连续层 + 30 次/秒微爆”，PM 通过（“底纹几乎听不到”）。音色四种：噗 15% / 木裂 13% / 啪 64% / 细响 8%，各带 `boost` 响度补偿（1.8× / 3.5× / 1× / 1.7×）。排程由 `fireCrackleRate` / `nextFireDelay` / `fireClusterOffsets` 定义（间隔 0.45–1.7 倍、10% 概率成簇）。强度：滑块 0–1 经 `intensityRange: [0.2, 0.8]` 映射；`minLevelRatio: 0.92` 让音量几乎不随强度变化（合计约 2.3dB），主要差在密度。当前电平：底纹约 −46dB、响爆 −30dB（相差约 16dB）。

- 篝火强度映射：滑块仍是 0–1，但 `ambienceLayers.fire` 配了 `intensityRange: [0.2, 0.8]`，把 0.2–0.8 映射成原来 0–1 的效果（0.2 → 最低、0.8 → 最高，两端各 20% 按端点处理）。
- 篝火的音量几乎不随强度变化（`minLevelRatio: 0.92`）：输出电平最低也有最高的 92%（-0.7dB），叠上响爆电平 0.75→0.9（1.6dB），**单声电平总差约 2.3dB**；强度主要改变密度（0.2→8 次/秒）。音色本身也不再随强度变化（原先 <0.6 时"啪"会更暗，导致低强度额外低约 4dB，已去掉）。实测强度 0 时每 16 秒约 4 声、峰值 0.34（不是静音），强度 1.0 时约 8–12 声/秒。
