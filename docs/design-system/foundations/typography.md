# 排版

排版用有限字号阶建立层级，用行高和字重表达结构，不靠大量字号或装饰制造差异。

## 字号阶

| 角色 | 字号 | 用途 |
| --- | --- | --- |
| caption | 12 | 辅助说明、状态、标签 |
| body | 14 | 正文、控件文字 |
| title | 16 | 面板标题、组标题 |
| heading | 18 | 卡片标题、局部重点 |
| large | 24 | 大号选项、局部强调 |
| page-title | 28 | 页面标题 |
| hero | 32 | 入口页或展示区标题 |
| display | 40 | 单点展示，不用于正文 |

- 界面文字以 12px 为下限，只使用偶数阶。
- 一屏内保持少量字号层级；层级不足时优先用间距、字重和颜色，而不是继续增加字号。
- 字号由样式类控制，不使用 `<small>` 等标签改变视觉大小；标签只承担原生行为。

## 行高与字重

| 场景 | 行高 |
| --- | --- |
| 标题 | 约 1.25 |
| 面板/卡片标题 | 约 1.4 |
| 正文与说明 | 约 1.6 |

- 行高与字号成对使用；不要让所有字号共用正文行高。
- 字重只使用 400 和 600；强调优先在字重、字号、颜色中选择一种，避免叠加。
- 长文本保持舒适行宽；避免全大写长句和过密行距。

## 图标

- 图标尺寸独立于字号，使用 18 / 20 / 24 固定档。
- 图标与相邻文字保持稳定的间距关系；不要用字号缩放图标。
- 图标只承担视觉表达，不做可访问名称或 ARIA 要求。

## 层级

- 每页通常只有一个主标题；区块标题按层级递减。
- 标题层级按内容结构使用，不用字号改变标题顺序。
- 数字、计时和参数需要对齐时使用等宽数字。
