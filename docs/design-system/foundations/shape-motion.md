# 形状与动效

形状和动效用少量固定档表达层级与状态，不靠装饰性效果制造差异。

## 圆角

| 档位 | 值 | 用途 |
| --- | --- | --- |
| small | 4 | 标签、徽标、小元素 |
| control | 8 | 按钮、输入框、选项 |
| panel | 12 | 面板、卡片、容器 |

- 圆角按元素层级选择，不按组件名称选择。
- 同一层级的元素使用同一档位；不为单个组件发明新圆角。
- 嵌套容器时，内层圆角不大于外层圆角。
- 圆形仅用于头像、指示点等确实需要圆形的元素。

## 层级与阴影

- 暗色主题优先通过表面色和边框表达层级，阴影作为辅助。
- 阴影保持克制，避免多层阴影和多个近似层级。
- 选中、悬停和错误状态优先使用边框、背景和文字颜色表达，不只依赖阴影。
- 焦点、选中和禁用状态需要保持可辨识，且与默认态有明确差异。

## 动效

- 只为状态变化添加动效，不为装饰添加持续动画。
- 使用统一短过渡，例如 0.15s；不同组件不各自定义零散时长。
- 明确过渡属性（颜色、边框、阴影），避免 `all`。
- 动效不阻塞操作，也不延迟状态反馈。

## 状态反馈

| 状态 | 表达 |
| --- | --- |
| 默认 | 基础表面、边框和文本层级 |
| 悬停 | 轻微提亮或边框变化 |
| 选中/激活 | 强调色边框、弱强调表面或强调色文字 |
| 禁用 | 降低不透明度、禁止指针，保持内容可辨识 |
