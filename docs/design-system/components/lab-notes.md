# LabNotes

## 用途

页面底部的「实现说明」折叠区，统一标题、间距和正文样式。用于补充实现边界和使用提醒，不承载操作。

## 结构

`details.lab-notes` + `summary.notes-summary`（固定标题「实现说明」）+ 多个 `p.notes-body`。

## 变体

无变体；标题固定，不通过 prop 修改。

## 状态

使用原生 `details` 展开/收起；不提供受控状态或动画。

## 行为

纯展示组件；展开状态由浏览器维护，页面切换后不保留。

## 内容

- `paragraphs` 每项一段文字，通常 1–3 段。
- 只写结论性限制，如数据来源、实现边界、使用提醒。
- 不写实现历史、调参过程或与页面主文案重复的内容。

## 元素与状态

原生 `details`/`summary`；折叠行为由浏览器提供。

## API

实现：`src/components/LabNotes.vue`。

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `paragraphs` | `string[]` | 是 | 按顺序渲染的正文段落 |

## 相关模式

放在页面内容末尾、`LabPageBody` 内；人声和环境音页面共用。
