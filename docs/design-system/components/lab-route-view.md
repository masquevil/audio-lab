# LabRouteView

## 用途

路由页的视图加载器：页面 chunk 只声明 `() => import(...)`，由本组件负责异步加载、加载提示和失败重试，使导航确认不被视图 chunk 阻塞。

## 结构

- 加载成功：渲染 `loader` 的默认导出组件。
- 加载中或失败：`LabPageBody` + `.route-status`，失败时追加「重试」按钮。

## 变体

无变体；状态由内部维护。

## 状态

| 状态 | 表现 |
| --- | --- |
| 加载中 | 「正在加载页面…」 |
| 失败 | 「页面加载失败，请检查网络后重试。」+ 主按钮「重试」 |
| 成功 | 目标视图 |

## 行为

- `watch` 监听 `loader`，`immediate` 启动首次加载。
- 每次加载递增版本号，旧请求结果不写入新状态；重试会重新发起同一 loader。
- 只处理视图模块加载；页面内部的数据请求由页面自己负责。
- 加载失败后保留重试入口，不自动重试。

## 内容

加载和失败文案固定，不接收插槽；页面视图自己负责页头和内容。

## 元素与状态

成功时渲染视图组件；加载态使用 `main` 容器承载提示。

## API

实现：`src/components/LabRouteView.vue`。

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `loader` | `() => Promise<{ default: Component }>` | 是 | 页面 chunk 内的动态导入 |

`src/pages/*.vue` 中的 `viewLoader` 必须定义为稳定常量，避免每次渲染产生新函数触发重新加载。

## 相关模式

- 与自动路由配合：页面文件只保留加载器和页面元信息。
- 需要预加载或进度条时另开需求，不在本组件加入空闲预取。
