# LabButton

## 用途

页面操作按钮，统一主/次层级与两档密度。用于提交动作，如开始、停止、试听、清除结果；不用于 tab、琴键、单选项或链接。

## 结构

原生 `button.lab-button` + 默认插槽。`disabled`、点击事件和 `class` 等属性透传到按钮本身。

## 变体

| 属性 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| `type` | `primary` / `secondary` | `secondary` | 主操作使用强调填充，次操作使用控件底色 |
| `size` | `default` / `compact` | `default` | `compact` 用于卡片和行内操作，字号 12px |

变体正交，可任意组合；同一区域只保留一个主操作。

## 状态

| 状态 | 表现 |
| --- | --- |
| 默认 | 控件表面 + 边框；主按钮为强调色填充 + 反色文字 |
| 悬停 | 次按钮换成控件悬停表面；主按钮保持填充并提亮 1.12 |
| 禁用 | 不透明度 0.45，指针为 `not-allowed`，不响应悬停 |

## 行为

- 固定 `type="button"`，不会提交表单。
- 点击和禁用由原生按钮承担；组件不维护加载、选中或播放状态。
- 需要切换文案时（如播放/停止）由调用方传入不同内容。

## 内容

- 使用动作 + 对象，如「开始录音」「试听参考 e」「清除结果」。
- 紧凑按钮仍保持 12px 字号下限。
- 默认保持纯文字，不混用不同字号或图标尺寸。

## 元素与状态

原生 `button`；按钮文字即操作名。

## API

实现：`src/components/LabButton.vue`。

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `type` | `'primary' \| 'secondary'` | `'secondary'` | 视觉主次 |
| `size` | `'default' \| 'compact'` | `'default'` | 密度 |

其余属性和事件透传给原生按钮。

## 相关模式

- 与 `PageHeader`、`LabPageBody` 组合构成页面操作区。
- 卡片内操作使用 `size="compact"`，主操作只保留一个。
