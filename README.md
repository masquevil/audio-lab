# Audio Lab

一个基于 Web Audio API 的浏览器声音实验室。

目前有两个实验：乐器演奏（钢琴、小提琴、竹笛三种合成音色，三个八度）与人声基础模拟（六个元音、四个声调、男女声合成预设）。无自动播放、录音或后端服务。请先调低系统音量，推荐使用现代 Chrome、Firefox、Safari。

## 使用方法

1. 打开首页，选择“乐器演奏”或“人声基础模拟”。
2. 乐器页按住琴键发声、松开停止；人声页先选择元音、声调与音色，再点击试听。
3. 播放中可随时停止，离开页面会释放音频资源。
4. 人声页的参考录音仅用于音色对比，合成结果仍是参数模拟，不等于自然中文朗读。

目前尚未实现辅音、拼音组合、任意文字朗读、环境音、编曲保存和音乐分析功能。

## 本地运行

需要 Node.js 24（>=24.13）和 pnpm 12.5.1。

```bash
pnpm install
pnpm dev
```

## 部署

`pnpm build`，将生成的 `dist/` 目录部署到支持 HTTPS 的静态托管服务即可。
