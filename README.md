# Audio Lab

一个基于 Web Audio API 的浏览器声音实验室。

目前只有一个最小实验：点击播放 440 Hz 正弦波，2 秒自动结束，也可手动停止。无自动播放、录音或后端服务。请先调低系统音量，推荐使用现代 Chrome、Firefox、Safari。

## 使用方法

1. 打开页面，先调低设备音量。
2. 点击“播放声音”试听，声音会在 2 秒后自动结束。
3. 点击“停止”可提前结束，结束后可再次播放。

目前尚未实现乐器、环境音、编曲保存、人声和音乐分析功能。

## 本地运行

需要 Node.js 24（>=24.13）和 pnpm 12.5.1。

```bash
pnpm install
pnpm dev
```

## 部署

`pnpm build`，将生成的 `dist/` 目录部署到支持 HTTPS 的静态托管服务即可。
