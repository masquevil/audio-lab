# Audio Lab

一个基于 Web Audio API 的浏览器声音实验室。

目前有三个实验：乐器演奏（钢琴、小提琴、竹笛三种合成音色，三个八度）、人声基础模拟（六个元音、四个声调、男女声合成预设）与环境音模拟（风声、雨声、雷声、篝火四种实时合成声部，可独立调节强度、组合播放并录制混音）。无自动播放、无后端服务。请先调低系统音量，推荐使用现代 Chrome、Firefox、Safari。

## 使用方法

1. 打开首页，选择“乐器演奏”“人声基础模拟”或“环境音模拟”。
2. 乐器页按住琴键发声、松开停止；人声页先选择元音、声调与音色，再点击试听。
3. 环境音页可单独播放任一声音并调节强度；多个声部会同时混合输出，“混音录音”录制当前混音并生成音频文件，不请求麦克风权限。
4. 播放中可随时停止，离开页面会释放音频资源并中断未完成的录音。
5. 人声页的参考录音仅用于音色对比，合成结果仍是参数模拟，不等于自然中文朗读。

目前尚未实现辅音、拼音组合、任意文字朗读、编曲保存和音乐分析功能。

## 本地运行

需要 Node.js 24（>=24.13）和 pnpm 12.5.1。

```bash
pnpm install
pnpm dev
```

## 部署

`pnpm build`，将生成的 `dist/` 目录部署到支持 HTTPS 的静态托管服务即可。
