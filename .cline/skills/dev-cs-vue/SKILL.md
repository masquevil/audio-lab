# 开发时的实现约束

具体规则以 [CONTRIBUTING.md](../../../CONTRIBUTING.md#代码规范基线) 为唯一来源；复用未变且仍在有效上下文中的规范，只补读本次涉及且缺失的章节，不因阶段切换重复全文读取。

- 修改组件或逻辑时应用「Vue 与 TypeScript」，修改样式时应用「样式」，修改文档时应用「文档」；不在 skill 中复制具体规范。
- 新增或迁移文件前按「目录结构与职责」确定归属，页面私有逻辑就近放置。
- 实现交互时同步处理失败、异步竞争、可访问性和资源释放；涉及音频时按需加载 web-audio。
- 按最小可验证实现推进，随改动运行针对性检查。最终命名、import 分组等完整扫描交由 code-review 阶段，不在每一步重复全项目审查。
