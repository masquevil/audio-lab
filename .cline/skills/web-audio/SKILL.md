# 浏览器音频检查

- 在用户手势内创建或恢复 AudioContext；默认静音待操作，检查 API 支持并显示失败信息。
- 明确节点连接图、输出增益和持续时间；低幅度起步并提示设备音量，使用包络降低边界爆音。
- start/stop 节点与 AudioContext 分别管理；OscillatorNode 只能 start 一次。处理重复点击、resume 失败、异步返回时组件已卸载等路径。
- 结束、手动停止和卸载均断开节点并释放不再使用的 context；长期音频再按需求设计共享引擎，不提前泛化。
- 验证未点击无播放、正常播放/停止/重播、自动结束、异常提示和释放。自动化状态/节点检查不能代替真实听感及目标设备测试。
- 涉及麦克风、录音、外部音频或模型时另行评审权限、隐私、跨域和处理成本；Web Audio 不是现成 TTS 或推荐服务。
