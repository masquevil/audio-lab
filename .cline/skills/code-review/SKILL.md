# 交付前统一审查

复用有效上下文中的 [规范](../../../CONTRIBUTING.md#代码规范基线)，只补读缺失、变更或新涉及的章节，不因进入 review 重读全文；检查本次完整变更和相关调用方。这是 AI 自检，不冒充独立研发 review 或 QA。

1. 对照需求逐项检查正常、异常、边界、异步及资源生命周期，确认没有越界实现或无用依赖。对照「目录结构与职责」检查文件归属与依赖方向，避免路由入口承载页面实现或私有逻辑被放入共享层。
2. 对照「Vue 与 TypeScript」统一检查 import 分组/路径/副作用顺序、SFC 结构、类型和数据推导。
3. 对照「样式」统一检查 class 命名、样式组织、原生 CSS 使用与颜色变量；具体标准引用规范，不在此重复定义。
4. 对照「文档」检查链接与表格；检查重复数据、可访问性及变更影响，跳过本次未涉及的主题。
5. 执行 pnpm check 及相关回归测试。发现问题记录位置、影响与修复；修复后重跑受影响检查。PM 返修后审查差异及关联风险，不逐次重复无关全量检查。
6. 将有验收价值的结论、实际验证和未覆盖项写回实施记录，再交付 PM。没有运行的检查明确标记；PM 确认前保持待验收。
